# GenAI Ethics Simulator

IS 201 (Computer Ethics) final group project by **Ctrl+Alt+Ethics**, University of the Philippines.

An interactive, rule-based simulator for **Scenario 4: Generative AI in Universities**. Users set institutional policy on generative AI in teaching, assessment and administration, and the model shows the effects on equity, governance, sustainability and other dimensions.

- **Live site:** https://is-201-ctrl-alt-ethics.github.io/genai-ethics-simulator/
- **Requirements:** [docs/requirements/final-req.md](docs/requirements/final-req.md)
- **Plan:** [PLAN.md](PLAN.md)
- **Due:** December 19, 2026

> The simulator illustrates ethical trade-offs. It does not predict real outcomes; all scores are hypothetical.
